회귀 확인은 미실행이다. 2026-09-07 자동 승인 검토가 실제 질문·제조 스키마·업무 정의·
조회 결과를 `api.openai.com`으로 보내는 테스트를 차단했다. 이유는 해당 payload와
목적지에 대한 명시적 승인 부족이다. 우회 실행하지 않았으며 실제 모델 정답률·비용·지연의
개선이나 운영 전환 조건 충족을 주장하지 않는다.

실행 스크립트가 준비되어 있다. 승인을 받은 후 고정된 코드/설정/DB에서 실행해야 한다.
