# 검증 상태 — 2026-09-07

현재 신규 실행 계획 경로는 비교 평가 전 실험 상태다. 서비스 API 8001은 보존된 PR #66 B (`22d209ab5d1178abb753aec2d67686ab07958121`)를 계속 사용한다. 신규 UI는 5174에서 기존 응답과 신규 응답을 모두 지원한다.

## 현재 완료한 확인

- 백엔드 기존/합성 기능 테스트 857개 통과.
- 신규 실행 계획 기능 명세 41개 통과: NULL, 중복, 조인 방향, 빈 결과, 별칭 출처, 조건 연산자, 그래프 패턴의 제한된 근거, 검토 모순, 병렬 예산.
- 실제 DB 통합 테스트 4개 통과. 신규 SQL JSONB/Graph list-of-maps 전달은 동일 행의 값·NULL·중복을 보존한다.
- 실제 모델 기능 확인 3개 통과: SQL 전체 개수, 검증된 빈 결과, Graph/SQL 독립 집계. 이는 개발 명세 확인이며 독립 일반화 평가 성적이 아니다.
- Ruff, Black, mypy(237파일), ESLint, TypeScript 빌드 통과. 기존 큰 번들 경고는 유지된다.
- 프런트엔드 테스트 51개 통과. 새 결과 표는 최종 결과만 사용하며 원천 데이터와 섞이지 않는다.
- 데스크톱/모바일 브라우저 확인 통과: 최종 값, 단위, NULL, 독립 결과 섹션, 정상 빈 결과와 미확정 구분. 응답은 합성 fixture이며 모델 품질 근거가 아니다.
- 신규 독립 120문항 Gold 검증 완료: SQL/Graph/혼합 각 30개 실제 읽기 검증, 모호/답변불가 각 15개 스키마 검토. 실행 문항 중 정상 빈 결과 27개.

## 진행 중

코드 고정 후 신규 독립 120문항과 이전 범용성90문항을 각각 3회 실행한다. 한 버전 안에서 두 평가셋을 병렬 처리하며 전체 동시 질의는 6개다. B와 개선안의 부하는 겹치지 않는다. 총 기본 요청은 1,260회이며 모호 질문의 확인 후속 요청은 별도다.

질문/정답/실패 목록은 구현에 사용하지 않는다. 결과 행 일치, 자연어 근거, 거절·확인·정상 빈 결과, 반복 안정성, 실제 모델 호출 수와 p95 지연을 분리한다. 독립 평가 완료 전 정확도 개선이나 운영 전환 가능성을 주장하지 않는다.

실행 계획 구조와 제한은 [실행 계획 리팩토링](executable-query-plan.md)을 참조한다. 과거 v1/B 단독 평가는 `blind-grounded-evaluation`에 보존되며 이번 신규 평가와 합산하지 않는다.
