## 아직 수행하지 않은 확인

실제 모델을 사용하는 서버 smoke test, 비공개 B/개선안 각 360건 비교, 기존 평가셋 최종
회귀 확인은 미실행이다. 2026-09-07 자동 승인 검토가 실제 질문·제조 스키마·업무 정의·
조회 결과를 `api.openai.com`으로 보내는 테스트를 차단했다. 이유는 해당 payload와
목적지에 대한 명시적 승인 부족이다. 우회 실행하지 않았으며 실제 모델 정답률·비용·지연의
개선이나 운영 전환 조건 충족을 주장하지 않는다.

별도 `blind-grounded-evaluation` 폴더의 고정 manifest, runner, paired summary와 비교
실행 스크립트가 준비되어 있다. 승인을 받은 후 고정된 코드/설정/DB에서 실행해야 한다.
모호함/답변 불가능/자연어 근거의 미검증 항목은 수동 검토 전 성공으로 세지 않는다.
평가 이후 구현을 수정하면 해당 평가 결과를 독립적인 일반화 성능 근거로 재사용하지 않는다.
