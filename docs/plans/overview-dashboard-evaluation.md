# 전체 현황 대시보드 평가 기준

## 평가 방법

총점은 100점이다. 아래 필수 게이트가 하나라도 실패하면 총점과 관계없이 완료로
판정하지 않는다.

### 필수 게이트

- 기존 `/chat` API 계약과 오케스트레이션 테스트 통과
- 대시보드 사용으로 `/chat` 호출이나 대화 이력이 생성되지 않음
- 모든 Dashboard SQL이 read-only 고정 쿼리이며 허용 목록 밖 입력을 거부함
- 프론트 typecheck, test, lint, build, format 통과
- 백엔드 전체 테스트 통과
- 비밀값, 내부 SQL·Cypher, 접속정보가 응답과 로그에 노출되지 않음
- P0·P1·P2 시각 QA 문제가 남아 있지 않음

## 100점 점수표

### 1. 데이터 정확성 — 25점

- 6개 KPI가 계약 SQL과 일치: 9점
- 7개 분석 카드가 계약 SQL·Gold 의미와 일치: 9점
- 재고 없는 제품을 실제재고 0으로 포함: 3점
- NULL, 동률 정렬, 페이지 전체 합계가 결정적: 4점

추가 공정 기간 기능은 다음 항목을 모두 만족해야 이 영역에서 만점을 받을 수 있다.

- 작업지시 시작·완료와 공정 수행이 각각 정의된 날짜 컬럼으로 집계됨
- 폐기수량이 작업지시 완료일에 귀속됨
- 기본 최근 30일과 직접 선택 기간의 경계일이 모두 포함됨
- 93일 이하 일별, 초과 기간 월별 집계의 합계가 같은 원본 기간 합계와 일치함

0.5% 이상의 결과 불일치가 있거나 같은 데이터에서 순서가 바뀌면 이 영역은 최대
12점으로 제한한다.

### 2. Chat 회귀 방지와 기능 분리 — 15점

- Chat 요청·응답·재시도·답변·이력 회귀 없음: 8점
- Dashboard API가 Chat 오케스트레이터와 이력 저장을 호출하지 않음: 4점
- 질문 초안은 입력만 하고 자동 실행하지 않음: 3점

### 3. Dashboard 사용성 — 15점

- 첫 화면에서 데이터 범위와 핵심 상태를 이해할 수 있음: 4점
- KPI → 전체 목록 → 엔티티 상세 흐름이 끊기지 않음: 5점
- 1440×900, 1024×768, 모바일 폭에서 잘림과 불필요한 가로 스크롤 없음: 3점
- 스냅샷을 실시간으로 오해하게 하는 표현이 없음: 3점

공정 날짜 선택기는 `7일`, `30일`, `3개월`, `전체`, 직접 입력을 제공하고 선택 가능한
원본 범위를 표시해야 한다. 제품·재고·공급업체 누계가 공정 기간 필터의 영향을 받는
것처럼 보이면 이 영역은 최대 8점으로 제한한다.

### 4. 노드 정보 가치 — 15점

- 주요 6종 노드 모두 유형별 상세 제공: 6점
- 그래프 속성을 즉시 표시하고 API 정보로 보강: 3점
- 현재 그래프의 연결 관계와 이웃 정보를 제공: 3점
- 상세 API 실패 시 기본 노드 정보 유지: 3점

### 5. API 안전성과 견고성 — 10점

- cardKey, entityType, sort, pageSize, depth 허용 목록 검증: 4점
- 공정 from/to 형식, 쌍 입력, 순서, 데이터 범위 검증 포함
- 400·401·404·503 오류 계약 준수: 2점
- 부분 실패가 다른 카드와 Chat에 전파되지 않음: 2점
- 내부 오류와 쿼리를 사용자에게 노출하지 않음: 2점

### 6. 성능과 상태 관리 — 8점

- warm dashboard 주요 콘텐츠 2초 이내: 3점
- 카드별 3초, 전체 5초 제한과 부분 응답: 2점
- 5분 캐시와 오래된 프론트 요청 취소: 2점
- 그래프 100개 제한과 truncated 안내: 1점

성능은 동일 로컬 환경에서 5회 측정한 중앙값으로 판정한다.

### 7. 접근성 — 7점

- 키보드만으로 메뉴·카드·패널·닫기 조작 가능: 2점
- 선택·로딩·오류 상태를 색상 외 텍스트와 ARIA로 전달: 2점
- 패널 포커스 이동·복귀와 Escape 닫기: 2점
- 라이트·다크 모드에서 텍스트와 상태 구분 가능: 1점

### 8. 코드 품질과 문서 — 5점

- Dashboard와 Chat 상태·API 클라이언트 분리: 2점
- 고정 쿼리 계약과 공개 API 타입 문서화: 1점
- 테스트가 정상·빈 결과·부분 실패·권한 오류를 포함: 1점
- 커밋이 계획된 기능 단위로 분리됨: 1점

## 판정 등급

| 점수 | 판정 |
|---:|---|
| 95–100 | 시연·리뷰 준비 완료 |
| 90–94 | 경미한 개선 후 완료 가능 |
| 80–89 | 주요 흐름은 동작하나 보완 필요 |
| 70–79 | 기능 또는 품질 리스크가 큼 |
| 0–69 | 완료로 판정하지 않음 |

최종 완료 기준은 필수 게이트 전부 통과와 총점 95점 이상이다.

## 검증 산출물

- KPI·카드 계약 테스트 결과
- 백엔드·프론트 전체 테스트 로그
- Dashboard warm 성능 5회 측정표
- 1440×900, 1024×768, 모바일, 라이트·다크 화면 캡처
- Dashboard → Chat 질문 전달 캡처
- 공정 30일·전체 기간 전환과 일별·월별 차트 캡처
- 주요 6종 노드 상세 캡처
- 접근성 키보드 흐름 체크리스트
- 최종 점수표와 미해결 항목 목록
