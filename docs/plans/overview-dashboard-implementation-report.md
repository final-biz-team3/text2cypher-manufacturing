# 전체 현황 대시보드 구현 결과

## 구현 상태

대시보드를 로그인 후 첫 화면으로 전환하고 기존 Chat을 `/chat`에 유지했다. 기존
디자인 토큰, Pretendard, 다크모드, 공통 버튼과 Sigma 그래프를 보존하면서 기준
이미지의 KPI 스트립, 2열 분석 카드, 480px 상세 패널 구조로 마이그레이션했다.

- `/` → `/dashboard`, 로그인 성공 → `/dashboard`
- 6개 KPI와 7개 분석 카드용 고정 SQL 계약
- overview 부분 실패, 카드 페이지·정렬, 5분 캐시, 요청 제한시간
- 제품·공급업체·작업지시·공정·작업장·폐기사유 상세 API
- 엔티티별 고정 1-depth Neo4j 이웃 조회와 100개 제한
- Dashboard → Chat 질문 초안 전달, 자동 실행 방지
- Sigma 기본 속성 즉시 표시와 상세 API 보강·실패 폴백
- 데스크톱 상세 패널, 모바일 전체 폭 상세 화면

## 시각·상호작용 검증

임시 API fixture로 네이티브 브라우저 viewport에서 다음을 확인했다.

- 1440×900 라이트·다크 대시보드
- 1024×768 대시보드와 480px 상세 패널
- 390×844 KPI·카드 단일 열과 전체 폭 상세 화면
- 카드 → 전체 목록 → 행 선택 → 엔티티 상세
- 선택 텍스트·`aria-selected`, 패널 포커스 이동과 닫기 후 복귀
- Dashboard 질문 초안이 Chat 입력창만 채우고 결과를 자동 생성하지 않음

캡처는 `artifacts/dashboard-qa/`에 저장한다.

## 기준 이미지 대비

1. 6개 KPI 스트립과 2열 분석 카드의 정보 계층을 동일하게 구현했다.
2. 우측 480px 상세 패널과 좁은 화면 전체 폭 전환을 동일하게 구현했다.
3. 기존 IT 브랜드, 색상 토큰, 다크모드와 Chat 스타일은 의도적으로 유지했다.
4. 기준 이미지의 미검증 매출·반려율·리드타임·제품 이미지는 넣지 않았다.
5. 모든 시간 표현은 실시간이 아닌 AdventureWorks 스냅샷으로 표시했다.

따라서 구조와 상호작용은 기준 이미지에 충실하고, 데이터 표현은 검증된 계약에
맞춰 의도적으로 제한했다.

## 평가와 남은 검증

현재 증거 기준 잠정 점수는 **92/100**이다. 기능·회귀·반응형·접근성 검증은
통과했지만 아래 두 항목은 실제 PostgreSQL·Neo4j 컨테이너가 실행되는 환경에서
확정해야 하므로 95점 완료 판정은 보류한다.

- Dashboard SQL 결과와 실제 Gold 결과 비교
- warm 상태 주요 콘텐츠 5회 측정 중앙값 2초 이내 확인

두 검증이 통과하면 평가 기준상 97점 이상으로 완료 판정할 수 있다.
